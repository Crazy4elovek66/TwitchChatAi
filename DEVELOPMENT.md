**TWITCH SMART BOT SYSTEM – DEVELOPMENT SPECIFICATION**

---

## 1. ОБЩЕЕ ОПИСАНИЕ ПРОЕКТА

**Цель:**
Создать интеллектуальную систему Twitch-бота, которая:

- подключается к Twitch через OAuth
- анализирует стрим (видео + голос + чат)
- формирует собственную базу знаний
- обучается в процессе работы
- взаимодействует в чате как живой человек
- поддерживает несколько аккаунтов
- имеет устойчивую личность для каждого аккаунта

Проект должен работать в двух режимах:

1) Режим обучения  
2) Основной режим  

---

## 2. АРХИТЕКТУРА ПРОЕКТА

Проект должен быть модульным и разделён на:

- Twitch Module (подключение, OAuth, чат)
- Voice Capture Module (ffmpeg / HLS)
- STT Module (Speech-to-Text)
- Vision Module (анализ кадров)
- Chat Parser Module
- AI Core (LLM)
- Memory System
- Personality Engine
- Knowledge Base
- Mode Controller (Training / Main)
- API Adapter (Yandex Cloud / Local)
- Multi-account Manager
- Anti-duplicate / Anti-spam system

---

## 3. РЕЖИМ ОБУЧЕНИЯ

**Цель режима:**
Создание базы знаний Twitch-контекста.

**Поведение:**

1. Подключение к Twitch аккаунту  
2. Подключение к выбранной трансляции  

3. Захват:
   - Видео (кадры)
   - Аудио (стримера)
   - Сообщений чата

4. Выполнение:
   - Транскрибация речи
   - OCR или анализ кадра
   - Парсинг чата

5. Анализ:
   - Выявление шуток
   - Выявление мемов
   - Повторяющихся фраз
   - Сленга
   - Взаимодействия стример ↔ чат
   - Эмоциональных реакций

6. Формирование структуры знаний:
   - Twitch slang
   - Мемы
   - Истории стримера
   - Поведенческие паттерны
   - Контекст реакций

**ВАЖНО:**
Режим обучения НЕ пишет в чат.  
Он только анализирует и сохраняет данные.

---

## 4. ОСНОВНОЙ РЕЖИМ

Работает в двух вариантах:

1) Через API (Yandex Cloud)  
2) Полностью локально  

Функционал идентичен.

**Принцип работы:**

1. Подключение через OAuth  
2. Подключение к стриму  

3. Анализ:
   - Голос
   - Картинка
   - Чат

4. Обновление базы знаний  
5. Генерация сообщений  
6. Отправка сообщений в чат  

---

## 5. ПОВЕДЕНИЕ БОТА В ЧАТЕ

Бот должен:

- Писать тематические комментарии
- Делать уместные шутки
- Реагировать на события
- Поддерживать разговор
- Не спамить
- Не отвечать без повода
- Иметь задержки как у человека
- Иногда молчать

---

## 6. СИСТЕМА ПАМЯТИ

Разделить память на:

### 1) Краткосрочная
- Последние сообщения
- Последние 2–5 минут стрима

### 2) Среднесрочная
- Текущий контекст стрима
- Активная тема

### 3) Долгосрочная
- Мемы
- Истории
- Сленг
- Личность
- Факты о стримере

---

## 7. PERSONALITY ENGINE

Для каждого Twitch-аккаунта:

- Русское имя
- Возраст (виртуальный)
- Характер
- Манера речи
- Уровень токсичности
- Частота сообщений
- Любимые эмоции
- Тип юмора

Бот всегда обязан:

- помнить своё имя
- придерживаться характера
- не выходить из роли
- не говорить, что он бот

---

## 8. СИСТЕМА ОБУЧЕНИЯ

Бот должен:

- Обновлять знания после каждой сессии
- Хешировать чанки аудио
- Избегать дублирования транскрипций
- Сохранять уникальные контексты
- Кластеризовать повторяющиеся мемы

---

## 9. ОБРАБОТКА АУДИО

- Использовать ffmpeg
- Работать с HLS Twitch
- Делать правильную нарезку PCM
- Учитывать RMS / Peak диагностику
- Проверять уникальность чанков

---

## 10. ОБРАБОТКА ВИДЕО

- Делать скриншоты каждые N секунд
- Прогонять через Vision модель

Извлекать:
- Игру
- Сцену
- Эмоции
- UI события

---

## 11. АНТИСПАМ СИСТЕМА

- Задержки отправки
- Рандомизация времени
- Проверка на повтор
- Ограничение частоты
- Поведенческий шум

---

## 12. МУЛЬТИАККАУНТЫ

Система должна:

- Поддерживать 1–N аккаунтов

У каждого:
- свой характер
- свои паттерны
- свой темп сообщений

Возможность прокси (опционально)
